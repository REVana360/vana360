# AI-assisted contributions

AI-assisted work follows the repository's contribution and evidence contract.
The contributor remains responsible for every submitted claim. Use the guides
below for evidence, public documentation, and comment rules.

The contributor must be able to explain each claim's source, scope, and limits.
Read [Evidence and claims](evidence-and-claims.md)
before adding an observation to documentation, configuration, or source.

Tracked public files describe the current project and its reproducible technical basis.
They do not contain prompts, session logs, model output, private paths,
internal work plans, or maintainer-only status.
